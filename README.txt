ADAM – instalovatelná webová aplikace (PWA)

Obsah: memy, galerie, výběr a přehrávání místních videí a zvuků, virtuální Adam, manifest a ikony.

DŮLEŽITÉ: ZIP není APK. Aby šla PWA instalovat s vlastní ikonou, nahraj obsah složky na HTTPS hosting. Potom na Androidu otevři adresu v Chrome → ⋮ → Instalovat aplikaci nebo Přidat na plochu.

Místní fotky/videa/zvuky se vybírají pouze po klepnutí na tlačítko. Tato prototypová verze je automaticky trvale neukládá, takže po obnovení stránky je může být nutné vybrat znovu.

Doporučený další krok: nahrát soubory na statický HTTPS hosting, například GitHub Pages. Pro skutečný APK je potřeba samostatné zabalení přes Android Studio nebo nástroj pro PWA.
